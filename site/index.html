All your coding agents, in one window.

Nushi is a Mac and Linux app for Claude, Codex, Pi and the other agents you already use, each running as your own CLI with your login and history. Review their diffs, work through their pull requests, and answer them from your phone.

over the Agent Client Protocol

The agent you already use

Nushi doesn't bring its own model or its own permissions. It starts the CLI you've logged in to, so a chat started here resumes in your terminal, and the other way round.

Review the work like a pull request

A side-by-side or unified diff of what the chat changed. Leave comments on its lines and they go to the agent as one message.

See what it writes, as it writes it

Markdown, HTML, images, PDFs, CSVs and Mermaid diagrams preview beside the chat and update live. Click into a file's source to edit it yourself.

Pull requests, blockers first

Checks, reviews and threads in one tab, with what blocks the merge at the top. Send a failing check to the agent in one click, and merge from the same tab.

Start from a Jira issue

Your issues and sprints as a task list. Start work opens a chat in a worktree named after the issue.

Terminals that outlive the app

Shells under each chat are kept by a small background daemon, so quitting Nushi doesn't stop a test run.

Keep it going from your phone

Follow your chats and answer an agent's questions while you're away from your desk. The link is end-to-end encrypted, through a relay you run yourself.

Install

macOS

brew install --cask afrase/tap/nushi

Or download the zip from Releases. Nushi updates itself from inside the app.

Linux

tar -xzf nushi-*-linux-amd64.tar.gz

x86_64 or arm64, glibc 2.34 or later. Steps in Installing Nushi.

Then open Nushi and set up an agent in Settings › Agents. The guide walks through it.
